Orbitron font for the game

This folder is intended to hold custom font files used by the game (TTF/OTF).

How to install Orbitron locally:
1. Open https://fonts.google.com/specimen/Orbitron in your browser.
2. Click "Download family" to get the ZIP.
3. Unzip and copy the TTF file (e.g. `Orbitron-Regular.ttf`) into this folder: `assets/fonts/`.
4. The game will automatically try to load `assets/fonts/Orbitron-Regular.ttf`. If it's not found, it will attempt to use a system-installed "orbitron" font, then fall back to "verdana".
